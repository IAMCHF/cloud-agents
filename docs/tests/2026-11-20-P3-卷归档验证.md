# 2026-11-20 P3 T3 卷归档验证

结论：**PASS**。已结束会话的 `ws-`/`state-` 两个 PVC 通过短生命周期归档沙箱打包，经 OpenSandbox 端口代理下载到控制面 `/archive`；恢复时上传回新沙箱并解压到原 PVC，`installation_id` 从 `broken` 恢复为原值，完成往返。

## 1. 归档

`GET /api/archive/plan` 返回 4 个已结束且超过保留期的会话（含目标会话），字段为 PVC claim 名与目标目录。

`POST /api/archive/run`：

```json
{"session_ids":["s-8de38edb4a814f45bd1563c2dd671e57"],"dry_run":false}
```

返回：

```json
{"archived":["s-8de38edb4a814f45bd1563c2dd671e57"],"dry_run":false,"errors":{}}
```

控制面 Pod 内 `/archive/default/s-8de38.../`：

```
state.tar.gz      359732 bytes
workspace.tar.gz     185 bytes
```

归档沙箱挂载 `ws-`/`state-` PVC，`entrypoint` 为 `python -c <archive agent>`，先 `tar czf` 再起 HTTP 文件服务；控制面通过 `GET /v1/sandboxes/<id>/proxy/18081/*.tar.gz` 下载。沙箱带 `networkPolicy defaultAction=deny`，下载仍可用（入站代理不受 egress 影响），归档后沙箱删除。

台账 `sessions.archived_at`/`archive_path` 已写入；审计 `session.archived`。

## 2. 恢复

1. 归档前通过临时沙箱读取状态盘 `installation_id`：`aed22034-d58b-4ca5-8568-fa41b1a80315`。
2. 用临时沙箱把 `/home/agent/.codex/installation_id` 覆盖为 `broken`。
3. `POST /api/archive/s-8de38.../restore?force=true` → **200**，返回 `archive_path`。
4. 再次读取状态盘：`installation_id` 恢复为 `aed22034-d58b-4ca5-8568-fa41b1a80315`。

恢复沙箱同样挂载原 PVC，`entrypoint` 为恢复模式 agent；控制面通过代理 `PUT /proxy/18081/workspace.tar.gz`、`state.tar.gz` 上传，agent 后台解压并写 `restore.done`；控制面轮询 `/status` 后在 finally 删除沙箱。审计 `session.restored`。

## 缺陷与修复

1. **恢复首次 500（代理上传 502）**：恢复沙箱 `wait_until_running` 返回时 HTTP 服务尚未监听；增加上传重试（20×1s）。
2. **重试仍 502**
   - 原因一：解压放在 PUT handler 内，201 未 flush，代理超时。
   - 原因二：`httpx` 异步生成器上传使用 `Transfer-Encoding: chunked`，agent 只按 `Content-Length` 读，未消费 body 就响应，代理重置连接。
   - 修复：agent 支持 chunked 解析；响应 201 后 `wfile.flush()`；解压移到后台线程（`_restore_if_ready`，锁保证只执行一次）。
3. **jscpd 生产克隆**：`sessions`/`archive` 的 `_ledger`/`_owned_session` 重复，抽到 `app/api/common.py`。

## 未覆盖风险

- 归档任务当前由管理面触发，无定时调度；生产需外部 Cron/Job 调用 API（或后续加 scheduler）。
- 每个归档/恢复会话会起一个短生命周期沙箱（约 5–10s），归档量大批量时需限流；本轮未测并发归档。
- 不删除源 PVC（`ARCHIVE_ENABLED` 只做归档，不做 retention 删除）；真实存储回收需后续策略。
- `/archive` PVC 2Gi 仅开发机；真实 NAS/对象存储与容量、NFS 非 root 权限留 D2。
- 归档 tar 含 SQLite WAL/SHM，在线归档已结束会话（无写入）时一致；若对 idle 会话归档需先停写（当前只归档 ended）。
- 阿里云/对象存储未实现，`archive_path` 目前为本地路径。
