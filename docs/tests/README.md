## 命名与内容约定

- 验收报告：`YYYY-MM-DD-阶段-类型.md`，日期在前，便于按时间排序。
- 报告至少包含：环境与版本、验证项与证据、缺陷与修复（含提交号）、未覆盖风险、复现入口。
- 不写密钥、内网地址、真实账号；截图与原始日志不入库（放本机或对象存储，报告里只记路径）。
- 结论要可复核：每条结果给出可观察证据（输出、状态码、指标值），不写“已验证”而无依据。
