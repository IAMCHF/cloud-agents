# 2026-11-20 P3 T5 终端与文件树验证

结论：**PASS**。Web 工作区新增右侧「终端 / 文件」面板：终端经控制面 `WS /api/sessions/{id}/terminal` 转发到沙箱内 execd PTY，文件树经 `GET /api/sessions/{id}/files`、`GET /api/sessions/{id}/file` 列目录与预览文本。kind 真链路验证 `echo t5-ok` 往返、`/workspace` 与 `/` 列目录、`/product_uuid` 预览均通过。

## 1. 文件树与预览

```text
GET /api/sessions/s-f946.../files?token=...&path=/workspace
→ {"path":"/workspace","entries":[]}

GET /api/sessions/s-f946.../files?token=...&path=/
→ 22 个条目（/app、/bin、/workspace…），字段 path/type/size/modified_at/owner/mode

GET /api/sessions/s-f946.../file?token=...&path=/product_uuid
→ 176fbb56-cb65-4d65-80ac-4b1255dc2855
```

`type` 实测为 `directory`/`file`/`symlink`；前端按 `type.toLowerCase().includes("dir")` 判定目录，并按目录优先、路径排序。文件预览上限 512KiB，超限返回 502。

## 2. 终端

用 Python `websockets` 经 Ingress 连接：

```text
ws://127.0.0.1/api/sessions/s-f946.../terminal?token=...
→ send {"type":"resize","cols":100,"rows":30}
→ send {"type":"stdin","data":"echo t5-ok\n"}
← ~0x01 + "echo t5-ok\r\n"
← "bash-5.2$ ...\r\n"
← "t5-ok\r\n"
```

（`~0x01` 表示 execd 二进制帧首字节，控制面剥离后转发。）脚本以 `t5-ok` 出现两次（PTY 回显 + 命令输出）判定成功。

## 3. 实现要点

- **execd 直连**：OpenSandbox HTTP 代理 `/v1/sandboxes/{id}/proxy/44772/...` 不支持 WebSocket 升级（握手超时），改为 `GET /v1/sandboxes/{id}/endpoints/44772` 取 Pod IP 直连；控制面与沙箱同集群可达。文件接口同样走直连，避免代理层额外限制。
- **鉴权按台账 token 反查**：`GET /files|/file` 与终端 WS 用会话 token，`ledger.find_session_by_token` 校验并核对 `session_id`；`running` 之外返回 401/409。多副本下请求可落在任意实例，不依赖本进程通道；`creating/running` 时按台账 `hub.ensure` 补通道。
- **终端桥接**：`terminal_socket` 先 accept 再 close（业务关闭码 4401/4409 可传达到客户端）；PTY 创建后直连 `ws://<endpoint>/pty/{id}/ws`，浏览器 text 帧原样转发（`resize`/`stdin`），execd 二进制帧首字节 `0x01` 剥离后转发、`0x03` 控制帧丢弃；断开后 `DELETE /pty/{id}` 回收。
- **前端**：`@xterm/xterm` + `@xterm/addon-fit`（MIT）；`TerminalPanel` 在 open 与 resize 时发送尺寸，卸载时先置 `disposed` 再关 socket，避免 close 事件写已销毁终端；`FilePanel` 自绘目录列表，点击目录下钻、文件走 `/file` 预览。
- **配置**：`EXECD_ACCESS_TOKEN`（默认空）用于 execd 启用鉴权时注入 `X-EXECD-ACCESS-TOKEN`。

## 4. 缺陷与修复

1. **WS 握手无 HTTP 响应**：首版直接用 `hub.authorize` 校验 token；REST 创建会话落在副本 A，终端 WS 按 `$arg_token` 粘性落到副本 B，B 无通道 → 未 accept 关闭，客户端只看到连接被重置。改为按台账 token 反查并 `hub.ensure`，任意副本可服务。
2. **前端卸载竞态**：`socket.close()` 触发 close 事件晚于 `terminal.dispose()`，可能向已销毁终端写入「终端已断开」。增加 `disposed` 标志，卸载后不再写。
3. **本机探测代理干扰**：Python `websockets` 受系统代理影响，连 nip.io 域名时无 HTTP 响应；探测脚本改用 `127.0.0.1` 并清空代理变量。生产无此问题（服务间直连）。

## 未覆盖风险

- 会话 token 仍在 URL query（与既有 `ws/session` 一致），Ingress/网关访问日志会记录；D2 入口需脱敏或改短期票据。
- 文件接口只读、仅文本预览；下载/上传、大文件流式、二进制预览未做。
- 终端不限制并发 PTY 数与空闲时长；每个连接创建一个 PTY，断开即删；异常断网依赖 execd 自身回收。
- 终端/文件请求经 Ingress 普通 HTTP 转发，未做单独的终端限流；`/api/sessions/*/files` 可读沙箱根文件系统（与终端同权限，属主 token 即可）。
- Web 覆盖率门槛未进本地 `check`（既有 L9 限制），`test:cov` 当前 72.9%，低于 80%；T5 新增面板单测覆盖 95%+，其余缺口在会话列表/OIDC 既有文件。
