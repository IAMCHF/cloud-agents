## 4. 实现与限制

- 仿真脚本进程内起「假 OpenSandbox + 控制面」两个 uvicorn；每个会话先连桥接 WS，再连客户端 WS，确保握手顺序稳定。
- 假桥接对每个 `turn/start` 发一次审批请求，等待客户端 `accept` 后发送流式增量与 `turn/completed`；客户端自动 accept 并记录次数。
- 仿真为单控制面进程，未覆盖双副本哈希漂移/Ingress 重试；该路径由 P2 HA 记录与 Web 新增退避重试兜底，D2 需在真实 Ingress 上复跑。
- 150 路为控制面连接与协议仿真，不代表 150 台真实沙箱容量；真实容量目标按 D2 执行机复跑 `bench/load.py`（改 `--sessions` 即可）。
- 真实沙箱数据来自最小对话 turn，是资源下界；工具执行/构建型负载需上线观测。
